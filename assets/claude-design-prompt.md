# Claude Design Prompt — Ask My Body 求诸己 UI Redesign

## Instructions for Claude

请为我的健康养生 App「Ask My Body 求诸己」设计 5 个手机页面（375×812 iPhone 尺寸）。

用 HTML + inline CSS 输出，每个页面一个 artifact。字体用 Noto Serif SC（Google Fonts）。

---

## Visual Direction（视觉方向）

参考中国传统工笔水墨画风格，核心美学关键词：

- **色调**：以宣纸米白(#faf8f3)为底，搭配淡粉(#f0c4c8, #e8a0a8)水墨晕染和薄荷绿(#c5d8c5, #a8c4a0)竹叶点缀
- **质感**：宣纸纹理感背景（用 CSS 噪点或渐变模拟），边缘有水墨洇开的毛边效果
- **装饰元素**：用 CSS/SVG 绘制简笔竹叶、梅花小枝、或水墨圆点作为点缀（不用图片，纯 CSS 实现）
- **边框风格**：卡片和分割线用淡墨水墨笔触感，不要硬直线，可以用渐变模拟毛笔痕迹
- **按钮**：圆角矩形（border-radius: 4px），淡粉底色或墨色描边，hover 时水墨晕开效果
- **整体氛围**：安静、内敛、清雅，像清晨打开一幅画卷

**禁忌**：不要现代 UI 的蓝色/紫色渐变，不要圆角卡片阴影，不要科技感。要的是文人画的气质。

## Technical Notes

- 所有页面 max-width: 375px, margin: 0 auto, 手机竖屏比例
- 字体：Noto Serif SC (300/400/600)
- 所有装饰用纯 CSS（radial-gradient, linear-gradient, pseudo-elements, SVG inline）实现，不用外部图片
- 每个页面单独一个 HTML artifact，可以独立预览
- 配色参考：
  - 背景底色: #faf8f3（宣纸）
  - 主粉色: #e8a0a8（梅花）
  - 淡粉: #f5dde0（晕染）
  - 竹绿: #a8c4a0（竹叶）
  - 墨色: #2a2520（正文）
  - 淡墨: #8a8078（辅助文字）
  - 极淡墨: #d5cfc8（分割线）
